# Alafeya Qaiser — Portfolio

A minimal editorial-style portfolio built with Next.js, React and Tailwind CSS.

## Run locally

1. Install Node.js 18.18+.
2. Extract this folder and open it in VS Code.
3. In the terminal, run:

```bash
npm install
npm run dev
```

4. Open http://localhost:3000

## Customize

- Replace `public/portrait.png` only if you want a different portrait. The supplied image is included unchanged.
- Edit project descriptions and links in `app/page.tsx`.
- Update styles in `app/globals.css`.
- Update contact/social links in `app/page.tsx`.

## Deploy

Push the project to a GitHub repository, import it into Vercel, and deploy with the default Next.js settings.
